# ── GNN — third fraud model (train_gnn_model.py stage) ───────────────────────
# Depends on the CPU-only torch pinned above; must stay below it in this file
# so pip resolves torch from the CPU index first.
#
# Deliberately WITHOUT the compiled torch-scatter / torch-sparse extensions.
# PyG >= 2.3 ships pure-PyTorch fallbacks for the ops this model uses
# (HeteroConv + SAGEConv, mean aggregation), and the compiled wheels are the
# single largest source of version-pinning breakage on python:3.12-slim.
# Verified 2026-08-14: torch-geometric 2.8 imports and trains with neither
# extension present. Only add them if profiling shows the fallback is too slow
# — at ~13k nominations per tenant it is not.
#
# Adds ~40 MB to the image on top of the torch already pulled in by
# sentence-transformers. NOT required by integrity-check: only the decoder head
# ships to inference, and it is plain torch.nn.
torch-geometric>=2.5.0,<3.0.0
